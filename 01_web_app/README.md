# Module 01: Web App

## หน้าที่และข้อมูลที่แสดง

หน้า Next.js ภาษาไทยสำหรับรับงบประมาณ การใช้งาน แบรนด์/รุ่น CPU และ GPU ที่สนใจ และชิ้นส่วนเดิม จากนั้นส่งคำขอไป Module 02 เพื่อจัดสเปกจากชุดความรู้รุ่น/สเปกที่มีแหล่งอ้างอิง

หน้าเว็บเป็นเครื่องมือวางแผน ไม่ใช่หน้าร้าน: ไม่มี stock, checkout หรือลิงก์ซื้อ แสดงราคาต่อชิ้นและราคารวมเป็นช่วงเมื่อมีผลค้นหาที่จับคู่ได้ พร้อมแหล่งและเวลาที่ค้น; หากราคาไม่ครบหรือสเปกยังตรวจไม่ได้จะแสดงข้อจำกัดและสถานะ degraded

## การตั้งค่าและรัน

```powershell
npm ci
npm run dev
```

เปิด `http://localhost:3000`. ตั้ง `NEXT_PUBLIC_API_BASE_URL` ใน `.env.local` เมื่อต้องการเปลี่ยน URL ของ Module 02 ห้ามใส่ secret ใน `NEXT_PUBLIC_*`.

```powershell
npm run build
```

## ข้อจำกัด

- รายการรุ่นที่รองรับอยู่ใน knowledge base ของ Module 03; รุ่นที่ยังไม่มีข้อมูลจะไม่ถูกแต่งขึ้น แต่ระบบจะแจ้งว่าต้องการข้อมูลเพิ่มเติม
- ราคาเป็นช่วงอ้างอิงจาก Google Shopping ผ่าน SerpApi ไม่ใช่ใบเสนอราคา/ราคาที่รับประกัน
- ไม่มี browser test suite; การ build ตรวจ TypeScript และ prerender เท่านั้น
